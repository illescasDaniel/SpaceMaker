        Use the URL or QR above on the same Wi‑Fi as this PC. The address must be your computer’s LAN IP (not 127.0.0.1 or localhost).

        Linux firewall (CachyOS / KDE)

        Allow inbound TCP 8765 for the SpaceMaker process. With UFW:

        sudo ufw allow 8765/tcp comment 'SpaceMaker LAN gallery'

        Or from the repo: sudo uv run task firewall-allow

        Plasma Firewall: System Settings → Network → Firewall → allow inbound TCP on this port.

        SpaceMaker checks UFW/firewalld rules and whether a LAN self-test can reach this port when the server is running.

        Third-party tools

        On first launch, SpaceMaker downloads pinned builds of these programs into a folder on your computer. If a download fails, install the tool with your package manager; SpaceMaker uses that copy when it is on your PATH.

        • FFmpeg / ffprobe — video
        • avifenc (libavif) — progressive AVIF
        • ImageMagick — thumbs / friendly JPEG
        • ExifTool — metadata
        • Android platform-tools (adb)

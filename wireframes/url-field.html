Agent note URL field contract (one component, used everywhere):
  • <input readonly> + icon Copy button, single line, never wraps, scrolls horizontally; the card never grows.
  • Click/focus in the input selects all text (easy manual copy).
  • Copy → clipboard; button shows a green “Copied” for ~1.5 s, then reverts. “Copied” only appears if the copy actually succeeded. The phone gallery is plain http:// on the LAN (no navigator.clipboard), so use navigator.clipboard when isSecureContext, else select + execCommand('copy'); if both fail, no “Copied”: the text just stays selected for manual Ctrl/Cmd+C.
  • Copy button has aria-label; “Copied” is announced via aria-live.
  • Replaces: #gallery-url div, #gallery-popup-url, and the .field URL inputs in the QR info panels.
